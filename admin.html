Cấu Hình ClickSend SMS & Resend Email

Nhập key tại đây để gửi ngay lập tức từ trình duyệt hoặc thêm vào biến môi trường Cloudflare.

1. ClickSend SMS (Gửi tin nhắn số Úc +61)

Lấy trong ClickSend Dashboard → Developers → API Credentials.

2. Resend.com (Gửi Email HTML chuẩn Atelier)

Lấy API Key (`re_...`) tại resend.com/api-keys.

💡 Mẹo để chạy tự động ngầm 24/7 khi khách vừa thanh toán:

Bạn có thể thêm các biến CLICKSEND_USERNAME, CLICKSEND_API_KEY, RESEND_API_KEY vào cùng chỗ với STRIPE_SECRET_KEY trên Cloudflare (Workers & Pages → wynnpages → Settings → Build → Variables and secrets).
