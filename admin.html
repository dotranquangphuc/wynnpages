Cấu Hình ClickSend SMS & Resend Email

Ghi đè hoặc nhập nhanh API Key ngay trên trình duyệt.

1. ClickSend SMS (Đã kết nối sẵn trên Cloudflare ✅)

Chỉ cần điền nếu bạn muốn đổi sang tài khoản ClickSend khác.

2. Resend.com (Gửi Email HTML chuẩn Atelier)

Lấy API Key (`re_...`) tại resend.com/api-keys hoặc thêm biến RESEND_API_KEY trên Cloudflare.

3. Tự Động Lưu File Lên Google Drive Của Bạn

Mặc định mọi file khách tải lên đã có nút ⬇️ Tải về máy trực tiếp ngay trên thẻ khách hàng. Nếu muốn tự động tạo thư mục tên tiệm và lưu vào Google Drive cá nhân: vào script.google.com → Dán mã vừa copy → Bấm Deploy → Web App (Anyone) → Dán link Web App vào ô dưới:

4. Cloudflare API Token (Tự động 100% Tạo Tên Miền & Lấy DNS)

Nhập Cloudflare API Token (quyền Zone:Edit & Workers:Edit) để khi gõ tên miền vào Bước 2, hệ thống sẽ tự động tạo Zone và tự lấy 2 Nameservers của khách về hiển thị.
