Cấu Hình ClickSend SMS & Resend Email

Ghi đè hoặc nhập nhanh API Key ngay trên trình duyệt.

1. ClickSend SMS (Đã kết nối sẵn trên Cloudflare ✅)

Chỉ cần điền nếu bạn muốn đổi sang tài khoản ClickSend khác.

2. Resend.com (Gửi Email HTML chuẩn Atelier)

Lấy API Key (`re_...`) tại resend.com/api-keys hoặc thêm biến RESEND_API_KEY trên Cloudflare.
